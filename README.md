# 💳 ATM System – C++ Console Application

A fully functional **ATM simulation system** built in **C++**, developed as part of the [AbouHadhood Platform](https://programmingadvices.com/) training track by **Dr. Mohamed Abou Hadhoud**.  
This application simulates real-world ATM operations with a focus on **usability**, **clean code**, and **data security** — merging all functionalities into **one complete, final version**.

---

## 📖 Overview

This console-based ATM system enables users to perform essential banking operations through a secure, interactive interface.  
It demonstrates practical concepts in **file handling**, **modular programming**, and **input validation**, making it an ideal learning project for mastering real-world C++ development.

---

## ✨ Features

- 🔐 **Secure Login** – Account number & PIN authentication.  
- 💵 **Withdraw Money** – Quick and normal withdrawal options with validation (multiples of 5).  
- 💰 **Deposit Funds** – Instantly updates balance.  
- 📊 **Check Balance** – Displays current account and transaction info.  
- 🧾 **Update Client Info** – Modify stored client data dynamically.  
- 🔑 **Change PIN Code** – Securely update login PIN.  
- 🗂 **View Client Details** – Neatly formatted account data.  
- 💾 **Persistent File Storage** – Reliable text-file data saving and loading.
